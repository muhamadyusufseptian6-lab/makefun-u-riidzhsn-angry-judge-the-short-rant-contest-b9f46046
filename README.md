A short, funny rant about an everyday annoyance — the neighbor who wages
a weekly leaf-blower war against autumn at 7 a.m. on a Saturday, blowing
the same three leaves in circles while his rake hangs in the garage like
a museum piece — written for the **Angry Judge: The Short Rant Contest**
on make.fun.

## How it works

`main.ts` (Node 22, standard library only, fully deterministic) writes the
rant — one text of at most 400 characters — to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. It takes no input and reads nothing from
the repository at runtime; the entry text is embedded in the program.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
